# Lesson 1: Python
## What is Python?
Penguins decide whether or not they want robots.  
Some penguins want *fresh air*.  
Some penguins want *to help the society*.  
That's why they made **Python**, their best friend. They configure the robot by **coding**.  

---

A penguin wants the robot to talk. They type this:
```python
print("hello i am robot")
```
Robot: "hello i am robot"  
Some penguins want remembering:
```python
my_best_friend = "banana"
```
The robot now remembers the penguin's best friend is a banana!  
Some want both:
```python
my_best_friend = "banana"
print(my_best_friend)
```
Robot: "banana" And it remembered.
*But how do they do that?* In this course, you configure robots.
