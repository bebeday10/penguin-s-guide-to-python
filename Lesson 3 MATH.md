# Lesson 2: MATH
## How math works, according to penguins
Penguins need to calculate. **But how**?  
By using the *Robot*™.
```python
2+7
```
It knows it's nine. It's just _too shy_ to say so.  
Penguins need it to talk.  
*How?*  
`print()`. **Again.**  
```python
print(2+7)
```
*Robot*™: `9`  
It says it.  
## Other ones
Division?
If you want floor division,
```python
print(8//3)
```
_Robot_: `2`  
Might seem stupid, but did their **job**.  
What about _normal division_?
```python
print(8/3)
```
_Robot_: `2.6666666666666665`  
Penguins think that's **a bit** too much.
Let's shorten it to two digits after the dot.
```python
print(f"{8/3:.2f}")
```
This makes it a string (like when the penguin says "hello" is a string),  
and makes it go till 2 decimals.  
Robot: `2.67` That's reasonable.
Subtraction?
```python
print(8-3)
```
`5`
Multiplication?
```python
print(8*3)
```
`24`
Squares?
```python
print(8**3)
```
