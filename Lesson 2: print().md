# Lesson 2: print()
Here is `print()`.  
Imagine it like penguins talking to each other.  
If one penguin wanted to say "*hello how are you*", it'd be like this:
```python
print("hello how are you")
```
It says:  
`hello how are you`  
The penguins don't need to physically say it anymore.  
The robot can say it for them.  
If the other penguin says "i'm doing fine":
```python
print("i'm doing fine")
```
